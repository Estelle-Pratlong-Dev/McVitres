# MC Vitres

Site vitrine WordPress réalisé pour présenter une activité professionnelle spécialisée dans les services de nettoyage et d'entretien.

> Projet WordPress — ancien projet

## Le projet

MC Vitres est un site vitrine développé sous WordPress afin de présenter l'entreprise, ses prestations et ses informations de contact.

Ce projet m'a permis de travailler sur la création et la personnalisation d'un site WordPress destiné à une activité professionnelle, avec une attention portée à la présentation des services et à l'adaptation du site aux différents supports.

## Fonctionnalités

* Présentation de l'entreprise
* Présentation des différentes prestations
* Mise en page responsive
* Navigation adaptée aux différents supports
* Gestion des contenus via WordPress
* Personnalisation de l'apparence du site

## Technologies

* WordPress
* PHP
* HTML
* CSS
* JavaScript
* MySQL

Ce projet fait partie de mes premières réalisations avec WordPress.
